One micro-confession in exactly two parts: a To: line naming who it was meant for, and the unsent message itself — one line, written exactly as it was typed, with no explanation after it. It stayed in drafts because no version of it ever sounded like it was enough.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt`.
